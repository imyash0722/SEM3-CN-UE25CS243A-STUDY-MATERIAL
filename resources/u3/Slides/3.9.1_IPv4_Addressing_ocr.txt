Stepwise Method for Designing Subnets ‘%

UNIVERSITY

Step 1: Determine the requirements
* Identify the number of subnets required.
* Determine the number of hosts needed per subnet.

Step 2: Determine the subnet and host bits
¢ Use the 2" - 2 formula to determine the number of subnet bits and host bits required.
* If multiple subnet masks satisfy the requirements, choose the one that provides better
future scalability.
If more subnets are likely to be added -> allocate more subnet bits.
If more hosts are likely to be added to existing subnets - allocate more host bits.
* Avoid using all available subnets or host addresses immediately. Leave room for future
growth.

Stepwise Method for Designing Subnets ‘%

UNIVERSITY

Step 3: Determine the subnet addresses

¢ Work in binary and list all possible combinations of the subnet bits.
* Set all host bits to 0 for each combination.

¢ Convert the resulting addresses to dotted-decimal notation.

* These are the subnet addresses.

Step 4: Determine the host addresses

* For each subnet, work in binary and list all possible combinations of the host bits.
* Keep the subnet bits unchanged.

¢ Convert the resulting addresses to dotted-decimal notation.

* These are the host addresses available within each subnet.

Step 4: Calculate Host Addresses for Each Subnet

* The final step is to determine the host addresses available in each subnet.

¢ Choose a subnet and keep the network and subnet bits unchanged. Then, list all possible
combinations of the host bits, starting from zero and counting upward in binary.

For example, consider the subnet 192.168.100.32:

* The first address, where all host bits are 0, is the subnet address.

¢ The last address, where all host bits are 1, is the broadcast address.

* The addresses between them are the host addresses available for that subnet.

* After the broadcast address, the next address begins the next subnet, which is
192.168.100.64.

Thus, the addresses follow this pattern:
Subnet address - Host addresses - Broadcast address - Next subnet
