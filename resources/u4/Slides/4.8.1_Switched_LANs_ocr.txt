Asking everyone on the LAN

A asks “who has B's IP address?” in a frame sent to FF-FF-FF-FF-FF-FF. Who receives it, and who
answers?

a Only Breceives it, and B then answers A b All nodes receive it; only B answers, to A

¢ All nodes receive it, and all of them answer A d Only the router receives it and answers for B

Answer: (b). All ones means 'everyone on this LAN', so B, C and D all read it. Only B's IP matches, and B replies to A alone.

After the exchange

A asked, B answered. Whose ARP table now has a new entry?

a Only A's (B's address) b A's and B's (each other's)

¢ Every node's on the LAN d Only the switch's table

Step 2 — Why Riis involved at all

A compares its own IP (111.111.111.111) against B's IP (222.222.222.222) using the subnet mask.
Different network portion = B is not on A's LAN. So A doesn't try to resolve B's MAC directly — it sends
the datagram to its default gateway, router R, and lets R forward it. This decision happens once, before
any ARP request is sent.

Step 3 — Hop 1: A resolves R's MAC (ARP on the left LAN)

host), but only R recognizes the target IP as its own.

ARP reply (unicast): R replies directly to A: "111.111.111.110 is at E6-E9-00-17-BB-4B.”

Hub or switch?

Eight PCs are plugged into one hub. Another eight are plugged into one switch. How many
separate collision domains does each have?

a Hub: 1; switch: 8 b Hub: 8; switch: 1

¢ Hub: 1; switch: 1 d Hub: 8; switch: 8

Answer: (a). A hub repeats every bit to every port, so all eight share one channel. A switch gives each port its own. With
full-duplex links nothing collides at all.

Smallest and largest frame

Worked solution

Destination 6 bytes, source 6, type 2, data 46 to 1500, CRC 4. What is the smallest frame, and
the largest?

dest. source type data CRC
6 bytes 6 bytes 2 bytes 46 — 1500 bytes 4 bytes

Smallest 6 +6 + 2 + 46 + 4 = 64 bytes (=512 bits, Session 2's collision budget)
Largest 6+ 6+ 2+ 1500 + 4 = 1518 bytes (1500 is the MTU from Unit 3)

Short data 20 bytes of data = 26 bytes of padding added to reach 46

Answer: 64 bytes and 1518 bytes. The preamble (8 bytes) is not counted in either.

Unreliable, by design

A frame carrying part of your download fails its CRC check at the second router. Who notices,
and who sends the data again?

a The second router asks the first one to resend b TCP at the sender notices the gap and resends

¢ The first router resends after a short timeout d Nobody: the file arrives with a hole in it

Answer: (b). Ethernet drops the frame silently: no acknowledgements, no resends. TCP sees the missing bytes and resends
the segment end to end.

Virtual LANs (VLANS)

What is a VLAN?

A Virtual Local Area Network (VLAN) is a method of dividing a single physical switched
network into multiple logical LANs. Devices belonging to the same VLAN can communicate
as if they are connected to the same physical network, even if they are connected to
different switches or different locations.

Why Do We Need VLANs?

A traditional switched LAN can form a single broadcast domain.

As the LAN grows:

* Layer-2 broadcast traffic increases.

* Broadcast traffic such as ARP, DHCP, and unknown-destination MAC frames can reach a
large number of hosts.

* This can create scaling and efficiency problems.

* Alarge common broadcast domain can also create security and privacy concerns.

Where does the broadcast go?

A PC on access port 5 (VLAN 20) sends a broadcast. Ports 1-2 are VLAN 10, ports 5-6 are VLAN
20, port 8 is a trunk carrying 10 and 20.

a To every port: broadcasts ignore VLANs b To port 6 untagged, and port 8 tagged 20

¢ Only to port 8, the trunk, tagged 20 d Only to the router, which handles broadcasts

Answer: (b). Flooding stays inside VLAN 20: its other access port gets it without a tag, and the trunk carries it tagged 20.
Ports 1-2 never see it.
