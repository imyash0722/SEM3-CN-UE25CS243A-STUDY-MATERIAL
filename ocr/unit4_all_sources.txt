IPv6 Prefix Notation

UNIVERSITY

* The prefix length is a decimal value that indicates the number of leftmost bits of an IP address that constitute the
network portion.

For example, consider the IPv6 address 2001:aaaa:bbbb:cccc:0:0:0:10/64.

* The prefix length 64 indicates that the first 64 bits represent the network portion, while the remaining 64 bits
represent the host (interface) portion.

* Therefore, the IPv6 subnet is 2001:aaaa:bbbb:cccc::/64, and 2001:aaaa:bbbb:cccc::10 represents a node within this
subnet.

Ethernet CSMA/CD Algorithm

1. NIC receives datagram from network layer, creates frame

2. If NIC senses channel:
if idle: start frame transmission.
if busy: wait until channel idle, then transmit

3. If NIC transmits entire frame without collision, NIC is done with frame!

signal
5. After aborting, NIC enters binary (exponential) backoff:
* after n collisions, NIC chooses K at random from {0,1,2, ..., 2m-1}.

NIC waits K'512 bit times, returns to Step 2
* more collisions: longer backoff interval

Virtual LANs (VLANS)

What is a VLAN?

A Virtual Local Area Network (VLAN) is a method of dividing a single physical switched
network into multiple logical LANs. Devices belonging to the same VLAN can communicate
as if they are connected to the same physical network, even if they are connected to
different switches or different locations.

Why Do We Need VLANs?

A traditional switched LAN can form a single broadcast domain.

As the LAN grows:

* Layer-2 broadcast traffic increases.

* Broadcast traffic such as ARP, DHCP, and unknown-destination MAC frames can reach a
large number of hosts.

* This can create scaling and efficiency problems.

* Alarge common broadcast domain can also create security and privacy concerns.
