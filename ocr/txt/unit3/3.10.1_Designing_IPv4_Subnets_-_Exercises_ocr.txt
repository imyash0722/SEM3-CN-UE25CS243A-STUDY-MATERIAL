Given the IP address 172.21.35.17, determine the network address using the appropriate address

mask.

1. Identify the class of the given IP address.

2. Determine the corresponding subnet mask in dotted-decimal notation.

3. Explain how the mask is used to separate the network portion from the host portion of the IP
address.

4. Determine the resulting network address.

Answer: Determining the Network Address Using a Subnet Mask
Given IP address: 172.21.35.17

1. Identify the class of the IP address

The first octet of the IP address is 172.

Class A: 1-126

Class B: 128-191

Class C: 192-223

Therefore, 172.21.35.17 is a Class B IP address.
