THE PROBLEM (Best-Effort Edge Networks)

o Unfiltered Ingress Storms

Dumb edge switches forward all packets blindly based solely on
destination IP.

o FIFO Backlog Saturation

Adversarial port scans and connection bursts exhaust TCP listen
queues and file descriptors.

o Severe Collateral Damage

Legitimate users suffer connection timeouts, packet drops, and
severe latency spikes.

Consequence: Handling malicious probes consumes 100% of
server CPU, causing severe packet loss for legitimate clients.

Network Intrusion Defense: Problem & Solution

THE SOLUTION (SDN-Based Edge Defense)

o Real-Time Telemetry Tracking

SDN Controller monitors Packetln connection velocity and
destination port diversity in real time.

e Dynamic OpenFlow Flow Control

Sliding-window engine detects anomalies in ~120 ms and pushes
high-priority drop rules in < 1 ms.

® Line-Rate Hardware Enforcement

Edge switches discard malicious frames at ingress datapath,
shielding server resources entirely.

Outcome: 100% of attacker traffic dropped in switch hardware;
legitimate clients enjoy 0.44 ms latency and 100% availability.
