## 💡 Study Tips

1. **Start with Unit Overviews** — Each unit's `00_overview.md` has a study checklist
2. **Master the Formulae** — Numerical problems are guaranteed in ISA/ESA
3. **Practice Numerical Traces** — Dijkstra, Bellman-Ford, CRC, delay calculations
4. **Know Protocol State Machines** — TCP handshake/teardown, DHCP DORA, ARP
5. **Review MCQ Patterns** — Each unit overview lists exam-relevant question types
