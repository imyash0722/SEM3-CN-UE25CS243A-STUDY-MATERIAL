# 1.6 Networks Under Attack

## Types of Attacks
1. **Malware**: Viruses, worms, botnets, ransomware (self-replicating, spreads exponentially)
2. **DoS/DDoS**: Overwhelm target with traffic
   - Vulnerability attack: few well-crafted messages
   - Bandwidth flooding: deluge of packets clogging access link
   - Connection flooding: many half-open TCP connections
3. **Sniffing/Eavesdropping**: Passive interception (wireless, cable, Ethernet broadcast)
4. **Spoofing**: Fake source IP/email (IP spoofing)
5. **Man-in-the-Middle**: Intercept and modify
6. **DNS Attacks**: Cache poisoning, hijacking

## Defense
- Firewalls, IDS/IPS
- Encryption (TLS/IPsec)
- Authentication, access control
- End-point authentication needed
