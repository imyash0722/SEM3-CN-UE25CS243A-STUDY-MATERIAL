IP addressing: Why not Classful Addressing?

Network portion - 8, 16, or 24 bits in length – known as
Class A, B and C networks respectively
A class C (/24) - accommodate only up to 28 - 2 = 254
hosts (two of the 28 = 256 addresses are reserved for
special use)
A class B (/16) subnet, supports up to 65,536 hosts

too small for many
organizations
too large, poor

A class A (/8) subnet, up to 16,777,214 hosts
Classful addressing, which is almost obsolete,

Find the class of each address.
a. 00000001 00001011 00001011 11101111
b. 11000001 10000011 00011011 11111111
c. 14.23.120.8
d. 252.5.15.111
Solution
a. The first bit is 0. This is a class A address.
b. The first 2 bits are 1; the third bit is 0. This is a class C address.
c. The first byte is 14; the class is A.
d. The first byte is 252; the class is E.

Stepwise Method for Designing Subnets
Step 1: Determine the requirements
• Identify the number of subnets required.
• Determine the number of hosts needed per subnet.
Step 2: Determine the subnet and host bits
• Use the 2ⁿ − 2 formula to determine the number of subnet bits and host bits required.
• If multiple subnet masks satisfy the requirements, choose the one that provides better
future scalability.
If more subnets are likely to be added → allocate more subnet bits.
If more hosts are likely to be added to existing subnets → allocate more host bits.
• Avoid using all available subnets or host addresses immediately. Leave room for future
growth.

COMPUTER NETWORKS
Stepwise Method for Designing Subnets
Step 3: Determine the subnet addresses
• Work in binary and list all possible combinations of the subnet bits.
• Set all host bits to 0 for each combination.
• Convert the resulting addresses to dotted-decimal notation.
• These are the subnet addresses.
Step 4: Determine the host addresses
• For each subnet, work in binary and list all possible combinations of the host bits.
• Keep the subnet bits unchanged.
• Convert the resulting addresses to dotted-decimal notation.
• These are the host addresses available within each subnet.

Example for Designing Subnets
Consider the internetwork, with Class C network address 192.168.100.0. The internetwork has
five data links, so at least five subnet addresses are required.
The two Ethernet networks have the highest requirement, with 25 hosts each.
Therefore, the subnetting requirements are:
At least 5 subnets and at least 25 host addresses per subnet.
Step 2:
Applying the 2ⁿ − 2 formula, 3 subnet bits and 5 host bits satisfy the requirements:
Subnets: 2³ − 2 = 6 subnets
Hosts per subnet: 2⁵ − 2 = 30 hosts
A Class C network with 3 bits borrowed for subnetting has the subnet mask:
255.255.255.224
= /27

Step 3:
The subnet bits are derived by marking the masked subnet bit space and then writing all
possible bit combinations in the space by counting up from zero in binary.

COMPUTER NETWORKS
Example for Designing Subnets
The subnet addresses are derived by filling in the network address to the left of the subnet
space, setting all host bits to zero to the right of the subnet space, and converting the results to
dotted decimal.

COMPUTER NETWORKS
Example for Designing Subnets
Step 4: Calculate Host Addresses for Each Subnet
• The final step is to determine the host addresses available in each subnet.
• Choose a subnet and keep the network and subnet bits unchanged. Then, list all possible
combinations of the host bits, starting from zero and counting upward in binary.
For example, consider the subnet 192.168.100.32:
• The first address, where all host bits are 0, is the subnet address.
• The last address, where all host bits are 1, is the broadcast address.
• The addresses between them are the host addresses available for that subnet.
• After the broadcast address, the next address begins the next subnet, which is
192.168.100.64.
Thus, the addresses follow this pattern:
Subnet address → Host addresses → Broadcast address → Next subnet
