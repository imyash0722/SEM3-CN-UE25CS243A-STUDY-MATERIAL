IPv6 Prefix Notation
• The prefix length is a decimal value that indicates the number of leftmost bits of an IP address that constitute the
network portion.
For example, consider the IPv6 address 2001:aaaa:bbbb:cccc:0:0:0:10/64.
• The prefix length 64 indicates that the first 64 bits represent the network portion, while the remaining 64 bits
represent the host (interface) portion.
• Therefore, the IPv6 subnet is 2001:aaaa:bbbb:cccc::/64, and 2001:aaaa:bbbb:cccc::10 represents a node within this
subnet.

Three Address Types
In IPv6, a destination address belong to:
Unicast Address (one-to-one) – defines a single interface
(computer or router). Packets sent to a unicast address
are delivered to the interface configured with that IPv6 address.
Multicast Address (one-to-many) – also defines a group of
computers, each member of the group receives a copy. Packets
sent to a multicast address are delivered to all interfaces
identified by that address.
Anycast Address (one-to-nearest) – defines a group of
computers that all share a single address. Packets sent to an
anycast address are delivered to the "closest" interface identified
by that address. "Closest" typically means the one with the best
routing metric
Broadcast Address (one-to-all) – × There are no broadcast
addresses in IPv6. Broadcast functionality is implemented using
multicast addresses.
